# 套餐档位分组与购买赠送（Package Tiers & Bonus Rewards）需求文档

- Feature: `package-tiers-bonus`
- 日期: 2026-09-18
- 状态: 已评审（用户确认全部关键决策）
- 关联: 扩展 `2026-09-17-credit-expiry-distill`

## 背景

上一版把有效期档位（月度 30 天 / 季度 90 天 / 年度 365 天）做成了套餐上的一个属性，
但用户想要的模型是：**档位是分组，每组里有多个套餐可选**。同时套餐除了基础积分，还
可以配置「额外赠送积分」或「赠送蒸馏券」，用来做促销与组合权益。

## 关键决策（用户确认）

1. **档位即分组**：套餐按有效期天数归入月度（30）/ 季度（90）/ 年度（365）三组，每组
   可包含任意多个套餐；分组由套餐自身的有效期天数决定，不新增独立分组表。
2. **赠送给独立字段**：套餐配置包含「基础积分 `credits`」与「赠送积分 `bonus_credits`」
   两个独立字段，购买后到账积分 = 基础积分 + 赠送积分；赠送积分与基础积分同一有效期，
   到期一起清零。
3. **赠送蒸馏券**：套餐配置包含「赠送蒸馏券 `bonus_tickets`」，购买成功即发放到用户账户；
   赠送的蒸馏券**不过期**，沿用现有蒸馏券永久有效的口径。
4. **两端都分组**：用户端钱包页与后台套餐管理都按月度 / 季度 / 年度分区展示。
5. **存量兼容**：已有套餐的赠送字段默认 0，迁移后行为不变。

## 术语

- **档位（Tier）**：有效期档位，取值为月度 30 天、季度 90 天、年度 365 天。
- **套餐（Package）**：某档位下可直接购买的一个积分商品，含基础积分、赠送积分、赠送
  蒸馏券、念念币价格、徽标与启用状态。
- **赠送积分（Bonus Credits）**：购买套餐时在基础积分之外额外到账的积分，与基础积分同
  一有效期。
- **赠送蒸馏券（Bonus Tickets）**：购买套餐时额外发放的蒸馏券，永久有效。

## 需求（EARS）

### 档位分组

- R1: The system shall 依据套餐的有效期天数把套餐归入月度（30 天）、季度（90 天）、
  年度（365 天）三个档位组。
- R2: WHEN 用户打开钱包页, the system shall 按月度、季度、年度三个分区展示套餐，
  分区内按排序值排列。
- R3: IF 某个档位组没有可用套餐, then the system shall 隐藏该分区。
- R4: WHEN 管理员打开套餐管理, the system shall 按月度、季度、年度分组展示套餐。

### 赠送配置

- R5: The system shall 在套餐配置中提供「赠送积分」与「赠送蒸馏券」两个独立字段，
  默认值为 0。
- R6: The system shall 在套餐卡片展示基础积分，并在赠送积分大于 0 时展示赠送积分，
  在赠送蒸馏券大于 0 时展示赠送蒸馏券。
- R7: IF 赠送积分或赠送蒸馏券为负数, then the system shall 拒绝保存并返回可读错误。

### 购买发放

- R8: WHEN 用户购买套餐成功, the system shall 按「基础积分 + 赠送积分」之和创建一条
  到期时间等于购买时刻加套餐有效期天数的积分批次。
- R9: WHEN 用户购买套餐成功且赠送积分为正, the system shall 在积分流水中记录含赠送的
  到账说明。
- R10: WHEN 用户购买套餐成功且赠送蒸馏券为正, the system shall 向用户发放对应数量的
  蒸馏券并写入蒸馏券流水。
- R11: The system shall 保证同一套餐购买的幂等重试只发放一次积分与蒸馏券。
